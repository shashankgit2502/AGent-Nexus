## Two genuine root-cause fixes (R3, each with a regression test), not patches

### 1. Alembic filter bug

The Alembic filter excluded `store_` but missed the bare `store` table, so autogenerate emitted:

```sql
DROP TABLE store
```

(the LangGraph store).

Fixed the prefix, extracted it to a unit-testable module.

### 2. Async graph vs sync persistence mismatch

The graph runs via `astream` (async) but the lifespan used the sync `PostgresSaver` → `NotImplementedError`.

Fixes:

- Switched to `AsyncPostgresSaver` / `AsyncPostgresStore`.
- Fixed a Windows `ProactorEventLoop` incompatibility with async psycopg.
- Fixed a session-vs-transaction GUC bug (mid-request commit was dropping the RLS scope).
